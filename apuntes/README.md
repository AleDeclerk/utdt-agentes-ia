# Apuntes personales · Arquitectura de Agentes IA (UTDT 2026)

Todo el material del curso en un solo lugar, para consultar después.

**Este repo es privado y tiene que seguir siéndolo.** Es material de un curso pago, y las transcripciones tienen los nombres de los compañeros.

## Qué hay

| Carpeta | Contenido |
|---|---|
| [`resumenes/`](resumenes/README.md) | Un resumen por clase (1 a 9), con un índice, las ideas que se repiten en el curso y las tareas pedidas |
| [`transcripciones/`](transcripciones/) | Transcripciones automáticas de Zoom de las clases 1 a 9: `.vtt` original y `.txt` con una línea por intervención |
| [`campus/`](campus/) | Todos los archivos del campus: slides por clase y, en `general/`, calendario, folleto e información útil |
| [`pre-curso/`](pre-curso/) | Copia del autodiagnóstico de requisitos previos (licencia MIT, de `matiaszabal/utdt-slides`) |
| [`notas/`](notas/) | [Calendario y logística](notas/calendario-y-logistica.md) y [problemas de setup ya resueltos](notas/setup-y-problemas.md) |

El resto del repo es el código del curso, tal como lo publica Matías, más un commit propio que cambia los modelos de los labs a Gemini 3.x.

## Cómo traer lo nuevo de Matías

El repo del curso es el remote `upstream`:

```bash
git pull upstream master
```
